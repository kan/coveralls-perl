# Security Policy

## Reporting a Vulnerability

If you find a vulnerability in Devel::Cover::Report::Coveralls, do not open a public issue. Report it through GitHub's [Private vulnerability reporting](https://github.com/kan/coveralls-perl/security/advisories/new) instead. Only the maintainer can see the report until a fix is published.

Please include:

- What the vulnerability is
- Steps to reproduce it
- The expected impact (for example, a token such as `COVERALLS_REPO_TOKEN` leaking into logs or to a third party)

Reports are checked and answered as soon as possible.

## Scope

In scope are the code in this repository and the [Devel-Cover-Report-Coveralls](https://metacpan.org/dist/Devel-Cover-Report-Coveralls) distribution on CPAN. Fixes are released only for the latest version.

Please report these elsewhere:

- Problems in Devel::Cover itself: [Devel::Cover](https://github.com/pjcj/Devel--Cover)
- Problems in the Coveralls service: [Coveralls](https://coveralls.io/)
- Vulnerabilities in other dependencies: the project that publishes the dependency
